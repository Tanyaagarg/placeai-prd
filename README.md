# PlaceAI — AI-Powered Placement Management Platform

> Product Requirement Document · v1.0
> Day 3 · Product Development Simulation

---

## What is this?

PlaceAI is a unified platform connecting students, placement
officers, and recruiters — powered by AI job matching,
automated drive management, and real-time analytics.

This repo contains the full PRD from a 1-day product simulation.

## Key decisions

- MVP in 12 weeks — Must Have features only in Sprint 1–2
- Mobile-first — 60%+ student traffic on phones
- AI matching — rules-based at launch, semantic in Sprint 3–4
- Target — Indian engineering colleges, 200–5000 students
